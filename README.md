# Tetris Game

## 项目概述

这是一个使用 C++ 和 EasyX 图形库实现的经典俄罗斯方块游戏。项目包括普通模式和上帝模式（AI 模式），支持图形界面、键盘输入、背景音乐和高分记录等功能。

## 功能介绍

### 1. 普通模式

- **游戏规则**：玩家通过键盘控制方块的移动、旋转和下落，使方块在底部形成完整的行以消除。
- **得分机制**：每消除一行，玩家将获得分数，连续消除多行将获得更高的分数。
- **游戏结束**：当新的方块无法在顶部生成时，游戏结束。

### 2. 上帝模式（AI 模式）

- **AI 算法**：AI 会自动选择最优的方块放置位置，以最大化游戏得分。
- **玩家互动**：玩家可以为 AI 选择特定的方块，观察 AI 的表现。

### 3. 图形界面

- **绘制方块**：使用 EasyX 图形库绘制方块和游戏界面。
- **UI 元素**：包含暂停按钮、菜单按钮等 UI 元素，提供良好的用户体验。

### 4. 键盘输入

- **控制方块**：玩家可以通过键盘箭头键控制方块的移动，空格键进行快速下落，P 键暂停游戏。
- **菜单选择**：在主菜单中，玩家可以通过鼠标点击选择不同的游戏模式。

### 5. 背景音乐

- **BGM 播放**：游戏开始时自动播放背景音乐，增强游戏氛围。
- **音量调节**：可以通过代码调整背景音乐的音量。

### 6. 高分记录

- **记录分数**：游戏结束后，如果玩家的分数进入前五名，将被记录在高分榜中。
- **显示高分**：可以在游戏中查看高分榜，激励玩家挑战更高分数。

## 运行环境

- **开发环境**：Visual Studio 或其他支持 C++ 的 IDE。
- **依赖库**：EasyX 图形库（需预先安装）。

## 编译与运行

1. **编译项目**

   使用 Visual Studio 或其他 C++ 编译器编译项目。确保所有源文件和头文件路径正确，并链接 EasyX 图形库。

2. **运行游戏**

   编译成功后，运行生成的可执行文件即可启动游戏。
